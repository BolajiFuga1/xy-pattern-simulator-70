# XY Pattern Simulator (5 from 1–70), phone version

A standalone, light-theme simulator laid out for iPhone 17. Each draw picks 5 numbers from 1–70 and plots them against columns 1–70, repeating up to 10,000 draws until a line of five repeats. It then picks four patterns from Z1–Z16, builds C1–C20 with the X/Y addition rules, and runs the C17 match test, for up to 1,000 runs.

Open `index.html` in any browser, or use the live GitHub Pages link.
